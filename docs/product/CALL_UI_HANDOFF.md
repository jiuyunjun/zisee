# 通话页 UI 小型交接包

日期：2026-09-10。设计负责人：主代理；实现：GPT-5.6 Sol；验收：主代理。

## 目标与边界

优化真实 Compose 通话页，以视频为主、操作可理解、状态可信、协作工具不遮挡彼此。沿用现有深色底、青绿色强调和红色挂断，不加依赖，不改媒体/权限/信令/视频 renderer 身份与坐标映射。主要修改 ActiveCall.kt，可调整 ArCallControls.kt 和 debug 预览；不重做首页。

## 已敲定设计

1. 顶栏：左侧姓名（单行省略，弹性宽度）及通话状态/时长；现场模式增加简短「对方现场」状态，不能替代连接状态。右侧最小化和免提，触控区至少 48dp；免提开启有明确选中外观和语义，关闭不暗示麦克风静音。
2. 底栏：固定次序「静音 / 摄像头 / 给你看 / 更多 / 挂断」。图标下显示 11–12sp 短标签，整个按钮可点且至少 48dp。静音后写「已静音」，摄像头关闭后写「已关闭」，共享时写「已暂停」，现场模式写「看我」。无障碍描述说清动作和当前状态。红色只用于结束/破坏操作，青色用于已选模式，普通按钮中性。5 项按可用宽度均分，上限约 440dp，挂断明显但不挤占其他控件。大字体允许按钮高度自然增长，不能裁切文字。
3. 视频与工具：保留 renderer 的固定调用点、拖动与切主画面行为。覆盖层在视频之上，渐变在交互工具之下。底栏、提示、AR 工具按实际测量高度预留空间，避免固定 118/132/140dp 导致重叠；窗口变化后位置安全。提示不挡操作。常规控制保留点击隐藏；TalkBack/touch exploration 下不自动消失，打开面板/确认框/正在操作时不自动隐藏。
4. 共享：单独的小卡片，第一行状态与「停止共享」，下方「文字清晰 / 动态流畅」选择，窄屏可换行，不用超宽单行。停止共享始终可达，控件隐藏后也保留。选项有 selected 语义。共享期间切换摄像头和开启现场不可用，并解释原因。
5. AR：独立工具区，标记类型（钉住/箭头/圈）为明确单选；撤销与清除单独成组，可换行，至少 48dp。保留清除确认。AR 工具与提示不叠在同一位置，操作重置隐藏计时。
6. 更多：标题「通话选项」，分组为「画面与共享」「AR 现场协作」「声音」，调试详情放最后。每组有背景/留白和清楚标题，动作使用全宽行或明确按钮，副说明使用次级文字；屏幕共享与前后摄切换靠前。降噪整行单选并使用 RadioButton 语义，避免父子重复点击节点。保留全部 AR 能力检测、确认与降级行为。
7. 统一文字对比度、圆角与留白（水平 16dp，组内 8–12dp），避免永久显示低对比教学文案。长姓名、320dp 宽、横屏和大字体不能把挂断/停止共享挤出可达区域。

- 运行 :app:assembleDebug :app:testDebugUnitTest :app:lintDebug；需要预览截图时构建 :app:assembleDebugAndroidTest。
- 复用 CallPreviewActivity/CallUiPreview 和 RtcSmokeInstrumentation 的无媒体预览入口，补充必要场景使静音/关摄像头/共享/长姓名可验证。不要为了截图发起真实呼叫。
- 验收矩阵：普通通话、静音/关画面、长姓名、双方双摄、共享准备/共享中、AR 标记与提示同时存在、更多面板、320dp 宽、横屏、大字体。UI 预览不代表真实 RTC/AR 能力验证。
- 向主代理交付：修改摘要、commit、命令与实际结果、截图/预览路径和未覆盖限制。主代理独立审 diff、运行验证并检查实际画面后决定通过或返工。
